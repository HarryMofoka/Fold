# Fold Runtime & External Dependencies Audit

This document provides a comprehensive, code-level audit of all external runtime dependencies in **Fold** (derived from Stirling-PDF). It determines whether Fold can deliver its promised functionality to an end user without requiring manual installation and configuration of development runtimes, command-line utilities, OCR engines, language models, or converters.

---

## 2. Code Invocation Pathways

To verify that these dependencies are not merely referenced in documentation, below are the exact code paths proving how each dependency is reached:

### A. Subprocess Execution Layer (`ProcessExecutor.java`)
All external command-line utilities pass through `stirling.software.common.util.ProcessExecutor`:
- **Enum `Processes`** (`ProcessExecutor.java:788–802`):
  `LIBRE_OFFICE`, `PDFTOHTML`, `PYTHON_OPENCV`, `WEASYPRINT`, `INSTALL_APP`, `CALIBRE`, `IMAGEMAGICK`, `TESSERACT`, `QPDF`, `GHOSTSCRIPT`, `OCR_MY_PDF`, `CFF_CONVERTER`, `FFMPEG`.
- **Runtime Paths** (`RuntimePathConfig.java:96–120`):
  Resolves binary names:
  ```java
  String defaultWeasyPrintPath = isDocker ? "/opt/venv/bin/weasyprint" : "weasyprint";
  String defaultUnoConvertPath = isDocker ? "/usr/local/bin/unoconvert" : "unoconvert";
  String defaultCalibrePath    = isDocker ? "/opt/calibre/ebook-convert" : "ebook-convert";
  String defaultOcrMyPdfPath   = isDocker ? "/opt/venv/bin/ocrmypdf" : "ocrmypdf";
  String defaultSOfficePath    = isDocker ? "/usr/bin/soffice" : "soffice";
  ```
  On non-Docker platforms (like bare Windows or desktop installations), these default to raw command strings (`"soffice"`, `"tesseract"`, `"gs"`, `"qpdf"`, `"weasyprint"`, `"ebook-convert"`), expecting them to exist in system `PATH`. If missing, `ProcessExecutor` throws `java.io.IOException: Cannot run program "<name>": CreateProcess error=2, The system cannot find the file specified`.

### B. Fallback Strategy in Core Operations
The codebase exhibits three distinct patterns when external dependencies are called:
1. **Multi-Tool Alternative Fallbacks** (e.g. `RepairController.java`):
   - Tries Ghostscript first (`gs -sDEVICE=pdfwrite`).
   - If Ghostscript fails or is disabled, falls back to QPDF (`qpdf --qdf`).
   - If QPDF fails or is disabled, falls back to pure Java PDFBox (`pdfDocumentFactory.load(...); document.save(...)`).
2. **Hard-Failing External Dependencies** (e.g. `ConvertEbookToPDFController.java`, `ConvertWebsiteToPDF.java`):
   - Immediately calls `ebook-convert` or `weasyprint`. If absent, the request fails with a 500 error.
3. **Configuration-Gated In-Process Alternatives** (e.g. `ConvertOfficeController.java`):
   - If `system.stirlingOfficeConversion: true`, routes to pure Java Apache POI bridge (`OfficeToPdfService.java`).
   - Otherwise, hard-fails with `ExceptionUtils.createLibreOfficeRequiredException()` if LibreOffice is missing.
